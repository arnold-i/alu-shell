# loops_conditions_and_parsing

Bash scripting project: loops, conditions and parsing.

| File | Description |
|------|-------------|
| 1-for_best_school | Displays "Best School" 10 times (for loop) |
| 2-while_best_school | Displays "Best School" 10 times (while loop) |
| 3-until_best_school | Displays "Best School" 10 times (until loop) |
| 4-if_9_say_hi | "Best School" 10 times, "Hi" after the 9th |
| 5-4_bad_luck_8_is_your_chance | bad/good luck on the 4th/8th iteration |
| 6-superstitious_numbers | Numbers 1-20 with superstitions (case) |
| 7-clock | Hours 0-12, minutes 1-59 |
| 8-for_ls | Lists names after the first dash |
| 9-to_file_or_not_to_file | Information about the "school" file |
| 10-fizzbuzz | FizzBuzz from 1 to 100 |
| 11-read_and_cut | username:uid:home from /etc/passwd |
| 12-tell_the_story_of_passwd | A story built from /etc/passwd (IFS) |
| 13-lets_parse_apache_logs | IP and HTTP code from Apache logs (awk) |
| 14-dig_the-data | Grouped/sorted IP + HTTP code (awk) |
